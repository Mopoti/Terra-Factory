## À valider avec le PO

1. Le clic gauche sur une pile de coffre prend **toute** la pile au curseur (avant : dans le sac) ; le clic droit prend la moitié au curseur (avant : dans le sac) ; **le sac se remplit seulement avec Maj + clic** ou en reposant la pile dans le sac. OK ?
2. PageUp / PageDown ont **trois sens** selon ce qu'on tient (étage de construction, inclinaison du tapis, étage de machine). Faut-il des touches distinctes (par exemple Début / Fin pour l'étage) ?
3. E et clic gauche sont équivalents ; F ouvre / utilise. Garder E uniquement pour « interagir » ?
4. Échap ferme d'abord une fenêtre, puis ouvre le menu : OK ?
5. Ctrl gauche = s'accroupir et Ctrl + clic = quantité : pas de conflit en jeu, mais en fenêtre le Ctrl ne s'accroupit pas. OK ?
